# Abstract

## AI-Based Detection of Fake or Manipulated Academic Certificates

Academic certificates are important documents used to prove educational qualifications during admissions, employment, internships, scholarships, and other verification processes. The increasing availability of digital editing and image manipulation tools has made it easier to alter certificate information such as names, marks, grades, dates, certificate numbers, signatures, and other visual elements. Manual verification of these documents can be time-consuming and may not always identify sophisticated digital manipulations. Therefore, there is a need for an automated system that can assist institutions and organizations in identifying potentially forged or manipulated academic certificates.

This project proposes an **AI-based academic certificate authenticity assessment system** that combines Optical Character Recognition (OCR), computer vision, image processing, machine learning, and deep learning techniques. The system accepts certificates in image or PDF format and first performs preprocessing operations such as resizing, noise reduction, contrast enhancement, image normalization, and perspective correction. OCR techniques are then used to extract important information such as student name, register number, course, marks, grades, dates, and certificate numbers.

The extracted information is analyzed using text processing and consistency-checking techniques to identify possible discrepancies. At the same time, computer vision and image-forensics methods examine the visual characteristics of the certificate, including text regions, layout, logos, seals, signatures, and potential signs of digital manipulation. A machine learning or deep learning model is used to classify certificate samples based on learned visual and textual features. Where a trusted certificate template or institutional record is available, the system can additionally compare the uploaded certificate against the expected template and verify extracted information against stored records.

The results from these different analysis stages are combined to produce an **authenticity or risk score** rather than making an absolute claim that a certificate is genuine or fraudulent. The system also generates an interpretable verification report that identifies suspicious regions, detected inconsistencies, and the factors contributing to the final assessment. A web-based interface is proposed to allow users to upload certificates and view the analysis results in a simple and accessible manner.

The project aims to demonstrate how multiple artificial intelligence and document-analysis techniques can be combined to support academic certificate verification. The proposed system can serve as a decision-support tool for educational institutions, recruiters, and organizations by reducing manual verification effort and helping identify certificates that require further investigation. The performance of the system will be evaluated using a controlled dataset containing genuine and synthetically manipulated certificate samples, using metrics such as accuracy, precision, recall, F1-score, and confusion matrix analysis.
